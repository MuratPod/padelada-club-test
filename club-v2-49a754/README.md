# Club Padelada — превью сайта клуба v2 (закрытое)

Новое закрытое превью сайта клуба на **прежней концепции зеркала** `MuratPod/padelada-club-test` (main @ 0640b64).
Прототип «Захватите свою комарку» с картой Испании **отменён** решением Мурата (26.10, 16:11) и сюда не перенесён.

**Не публикуется на padelada.club, не вливается в main, PR не создавался.** Все страницы: `noindex,nofollow,noarchive`, `robots.txt` с `Disallow: /`.

## Ссылка и маршруты

База: `https://muratpod.github.io/padelada-club-test/club-v2-49a754/`

| Маршрут | Что |
|---|---|
| `index.html?lang=ru` | Главная: что такое клуб и что он даёт → корт → фото комарок + поиск → афиша → «Станьте капитаном своей комарки» → вопросы → скачать |
| `comarca.html?id=girones&lang=ru` | Занятая комарка (демо): название, карта комарки, число членов, место в рейтинге, афиша, «Войти» и «Скачать приложение» |
| `comarca.html?id=alt-camp&lang=ru` | Свободная комарка: карта, «Стать капитаном» + 3 условия |
| `preguntas.html?lang=ru` | ЧаВо, ровно 5 вопросов |

Языки `?lang=` — `es` `ca` `en` `ru` `uk` (запоминается). `?platform=ios|android|desktop` — принудительная платформа для кнопок приложения (на телефоне кнопка ведёт сразу в нужный магазин; на компьютере открывается окно с QR и обоими магазинами).
Страницы комарок открываются для любой из 43 комарок (`id` — из `shapes.json`; 12 из них «заняты» в демо-данных, см. `js/data.js`).

## Структура

```
index.html  comarca.html  preguntas.html  robots.txt
css/site.css          — тёмная тема D4, токены Festa, шрифты, анимации, reduced-motion
js/i18n.js            — 5 языков, ссылки на приложение, юридические ссылки
js/data.js            — ДЕМО: статусы комарок, члены, места, афиша
js/app.js             — шапка/подвал, рендер, поиск, афиша, диалог загрузки, параллакс
shapes.json           — контуры 43 комарок (производные OpenStreetMap, ODbL)
assets/               — фото (WebP), шрифты (woff2), логотип, бейджи магазинов, QR
shots/                — скриншоты проверок
```

Статический сайт без сборки. Локально: `python3 -m http.server` в этой папке (карта комарки загружает `shapes.json` по HTTP).

## Дизайн

Тёмная тема D4 (`#0A1124` / поверхность `#141C30`), тонкий Montserrat Alternates 300 + Golos Text, без градиентов, свечений и теней (стекло = размытие + рамка 1 px; затемнение фото — плоская подложка). Кинематографичные секции: медленный ken-burns и параллакс фона, горизонтальная лента комарок с параллаксом внутри карточек, появление блоков при прокрутке, отклик на наведение и нажатие. При `prefers-reduced-motion` анимации и параллакс отключены, контент виден сразу.
Флаговые цвета только на картах: красный `#E8393F` — есть клуб, жёлтый `#F1BF00` — свободна.

## Что взято из зеркала и из PR #1

- Из зеркала: тональность и тексты (клуб, «две проверенные игры за 7 дней с четырьмя разными людьми», качества клуба, капитаны), набор шрифтов, логотип, бейджи магазинов, QR, ссылки на приложение и юридические страницы.
- Из PR #1 `fix/no-people-hero` (ветка не вливалась, только прочитана): принципы «без фото людей», «без текстов про Plus», обращение «вы» (ru) / «ви» (uk), а также фото мест из `assets/places/`. Скриншоты приложения из PR (`media/v3`) **не** использованы: на них имена и уровни игроков, светлая тема.
- Из закрытых прототипов `padelada-club-proto-*`: только код контуров комарок (OSM) и каркас i18n. Главная «захват комарки» и карта Испании не использованы.

Подробности решений — в `DECISIONS.md`, источники — в `CREDITS.md`.
