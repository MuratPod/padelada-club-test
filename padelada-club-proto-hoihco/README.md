# Padelada Club — кликабельный прототип (закрытое превью)

Статус: **прототип для просмотра. Не опубликован, не слит, не задеплоен.** Страница `noindex,nofollow`, лежит в папке с неугадываемым именем; на неё нет ссылок с других страниц.

## Как открыть
Откройте `index.html` по адресу превью (см. отчёт) или локально: `python3 -m http.server 4488` в этой папке → http://localhost:4488/index.html (по `file://` карта не загрузится — fetch).

## Маршруты (hash-router, один HTML)
| Маршрут | Что это |
|---|---|
| `#/` | Главная: карта Испании, легенда, поиск |
| `#/comarca/<id>` | Страница комарки: свободная → капитан; занятая → афиша и кнопки |
| `#/faq` | FAQ, 5 вопросов, аккордеон |

Параметры: `?lang=es|ca|en|ru|uk` (иначе localStorage/язык браузера, по умолчанию es); `?platform=ios|android|desktop` — только для проверки выбора ссылки на стор.
Примеры: `?lang=ru#/comarca/alt-camp` (свободная), `?lang=ru#/comarca/barcelones` (занятая).

## Что РЕАЛЬНОЕ
- Дизайн-язык (D4): цвета, шрифты, стекло, motion.
- Контуры карты (OSM, см. CREDITS.md) и названия комарок.
- Ссылки на приложения: iOS `https://apps.apple.com/app/id6819019168`, Android `https://play.google.com/store/apps/details?id=com.padelada.app`.
- Тексты на 5 языках (ru — «вы», uk — «ви»).

## Что ДЕМО (выдумано, помечено в коде `DEMO_FLAG` и маленькой пометкой «демо-данные» в футере)
- Статусы свободна (жёлтый флага #F1BF00, обводка) / занята (красный флага #E8393F, сплошная заливка), см. DECISIONS.md (`js/demo.js`, генератор `tools_gen_demo.py`, детерминированный): 79 из 198 занято; 26 крупных комарок/провинций — занятые с высокими местами.
- Число участников и место в рейтинге комарок.
- Афиша турниров и игр (`eventsFor()` в `js/app.js`): даты, клубы, форматы, уровни, свободные места. Названия клубов — вымышленные испанские/каталонские.
- Уровни показаны диапазонами по шкале 0–7 — алгоритма рейтинга на сайте нет.

## Чего на сайте НЕТ (по ТЗ)
Plus, награды, таблица кандидатов, форма заявки страны, заявки капитанов, алгоритм рейтинга, имена игроков, чат, цены и лимиты.

## Структура
`index.html`, `css/app.css`, `js/i18n.js` (словари + ссылки), `js/demo.js`, `js/app.js`, `data/map.json` (467 КБ — карта), `assets/fonts/`, `robots.txt`, `shots/` (ключевые скриншоты).
Вес без карты ≈ 149 КБ (лимит 1,5 МБ).

## Доступность
Клавиатура: области карты фокусируются Tab (подсветка), Enter/Пробел открывает комарку; кнопки зума — кнопки; поиск — combobox со стрелками/Enter/Esc; у всех 198 областей `aria-label`; контраст ≥ 4,5:1; `prefers-reduced-motion` отключает анимации; tap-цели UI ≥ 48 px.
