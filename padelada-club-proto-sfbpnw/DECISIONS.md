# DECISIONS — вопросы к Мурату и принятые решения

## Открытые вопросы
1. **«Основатель навсегда при 16 участниках».** Формулировка двусмысленна. В тексте условия 2 написано коротко: «Основатель навсегда при 16 членах». Подтвердите точный смысл (капитан, собравший 16 членов, остаётся основателем навсегда?) — поправлю во всех 5 языках.
2. **Кнопка «Войти» для члена клуба.** Отдельной ссылки нет → открывает ту же ссылку на приложение по платформе (на десктопе — окно с обеими ссылками). Нужен ли deep link / universal link?
3. **Слой карты.** Реальные комарки есть только для Каталонии, Арагона, Валенсии, Галисии. Остальное — провинции (плейсхолдер). Нужен ли единый слой комарок для всей Испании (источник и перечень — решение за вами; в Мурсии, Балеарах, Астурии, Эускади комарки определяются иначе)? Отсутствуют Сеута/Мелилья и комарка l'Horta Oest (нет в OSM).
4. **Мелкие области на карте.** Комарки на телефоне меньше 48 px. Смягчено: поиск, зум-кнопки, pinch-zoom, анимация фокуса. Достаточно ли, или добавить список комарок под картой?
5. **Интенсивность заливки «занята»** (корал, плотная) и «свободна» (мятный контур + лёгкий тон) — подтвердить баланс; при полной карте занятых будет много «красного».
6. **Показывать ли статус соседних комарок** на странице комарки (сейчас — только мини-карта без статусов).
7. **Источник рейтинга комарок** (место). Сейчас — демо. Откуда в реале и как часто обновлять?
8. **Атрибуция OSM** (ODbL) — где показать на сайте (предлагаю ссылку «О карте» в футере).
9. **Уровни в афише** — диапазон по шкале 0–7 (демо). Показывать или скрыть уровень на публичной афише?

## Принятые решения
- Только Испания, один HTML + hash-router (без сборки, без зависимостей).
- Названия комарок всегда латиницей (как в оригинале), во всех языках.
- «Paddy» на сайте не упоминается.
- Для страницы занятой комарки — только место в рейтинге, без имён и чата.
- Демо-статусы детерминированы, чтобы скриншоты были воспроизводимы.
- Дизайн: тёмная тема D4, стекло только blur + 1px рамка, без теней/свечения/градиентов.
