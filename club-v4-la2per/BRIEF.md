# padelada.club · club-v4 макет (для club-test)
Решения Мурата 01.11. D4 dark (ночной корт club-v3). Mobile-first 390/768/1440. Прод — только после «да» Мурата.
## Порядок главной
Hero (твоя комарка) → 3 входа (A свой / B новый без app / C другая страна) → комарки ES (места/зоны, счётчики) → Padelada World → FAQ (FAQ5: без ограничений, любая комарка + Falta uno).
## Экраны
index · mapa (только ES) · comarca (публ. тизер) · entrar (Apple/Google stub) · no-miembro · mi-comarca · cabina (#falta #torneos #miembros #perfil) · fundador-deberes · fundar-app · world (+форма, success).
## Правила
Без Plus/Max/цен/наград, без «бесплатно/навсегда». Без Paddy и чата (только app). Основать комарку — только app (deep link), GPS нет. Публично — без имён, инициалы. Рейтинг один личный. Без «алгоритма». Открытые турниры видны всем. Fundador = капитан на старте, золото #FFC963; обязанности ДО активации. Жалоба на Fundador — только члены комарки, авто-поток не рисуем.
## Языки
